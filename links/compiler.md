# 编译器

Bun 可以把 TypeScript 或 JavaScript 程序编译成单个可执行文件，在没有安装 Bun 的机器上直接运行。

## 入门

- [编译器](https://bun.com/docs/compiler) — 将程序编译为单个可执行文件
- [单文件可执行程序](https://bun.com/docs/compiler/executables) — `bun build --compile` 用法
- [字节码缓存](https://bun.com/docs/compiler/bytecode) — 字节码缓存优化

## 提前编译（AOT）

- [提前编译](https://bun.com/docs/compiler/aot) — 构建时编译为机器码
- [类型](https://bun.com/docs/compiler/types) — `bun compile` 如何使用你的类型
- [类型化百分比](https://bun.com/docs/compiler/explain) — 让程序的更多部分获得类型
- [体积](https://bun.com/docs/compiler/size) — 减小可执行文件体积（`--trim`）
- [兼容性](https://bun.com/docs/compiler/compatibility) — 编译后可执行程序的行为差异
- [测试与调试](https://bun.com/docs/compiler/debugging) — 调试编译后的程序
- [库](https://bun.com/docs/compiler/libraries) — 哪些 npm 包不适用于编译
- [疑难解答](https://bun.com/docs/compiler/troubleshooting) — 常见错误与修复方法
