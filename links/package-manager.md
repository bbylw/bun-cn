# 包管理器

Bun 内置了兼容 Node.js 的包管理器，速度远超 npm、yarn 和 pnpm。

## 命令行工具

- [`bun install`](https://bun.com/docs/pm/cli/install) — 安装所有依赖
- [`bun add`](https://bun.com/docs/pm/cli/add) — 添加依赖
- [`bun remove`](https://bun.com/docs/pm/cli/remove) — 移除依赖
- [`bun update`](https://bun.com/docs/pm/cli/update) — 更新依赖
- [`bun link`](https://bun.com/docs/pm/cli/link) — 链接本地包
- [`bun pm`](https://bun.com/docs/pm/cli/pm) — 包管理工具
- [`bun outdated`](https://bun.com/docs/pm/cli/outdated) — 检查过时的依赖
- [`bun publish`](https://bun.com/docs/pm/cli/publish) — 发布包到 npm
- [`bun patch`](https://bun.com/docs/pm/cli/patch) — 修补依赖
- [`bun why`](https://bun.com/docs/pm/cli/why) — 查询依赖被安装的原因
- [`bun audit`](https://bun.com/docs/pm/cli/audit) — 安全审计
- [`bun info`](https://bun.com/docs/pm/cli/info) — 查看包信息

## 功能特性

- [全局缓存](https://bun.com/docs/pm/global-cache) — 全局包缓存
- [全局存储](https://bun.com/docs/pm/global-store) — 全局包存储
- [隔离安装](https://bun.com/docs/pm/isolated-installs) — 隔离安装模式
- [工作区](https://bun.com/docs/pm/workspaces) — Monorepo 工作区
- [目录](https://bun.com/docs/pm/catalogs) — 依赖目录管理
- [生命周期脚本](https://bun.com/docs/pm/lifecycle) — 生命周期钩子脚本
- [过滤](https://bun.com/docs/pm/filter) — 工作区过滤
- [锁文件](https://bun.com/docs/pm/lockfile) — 锁文件格式
- [作用域与注册表](https://bun.com/docs/pm/scopes-registries) — 作用域和注册表配置
- [覆盖与解析](https://bun.com/docs/pm/overrides) — 依赖覆盖
- [安全扫描器 API](https://bun.com/docs/pm/security-scanner-api) — 安全扫描器
- [`.npmrc`](https://bun.com/docs/pm/npmrc) — .npmrc 配置支持
