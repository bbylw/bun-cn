# 测试运行器

Bun 内置了类 Jest 的测试运行器 `bun test`，速度极快，支持 TypeScript 开箱即用。

## 核心功能

- [`bun test`](https://bun.com/docs/test/index) — 测试运行器入口
- [编写测试](https://bun.com/docs/test/writing-tests) — 如何编写测试
- [生命周期钩子](https://bun.com/docs/test/lifecycle) — beforeAll / beforeEach 等
- [Mock](https://bun.com/docs/test/mocks) — 模拟函数和模块
- [快照](https://bun.com/docs/test/snapshots) — 快照测试
- [日期与时间](https://bun.com/docs/test/dates-times) — 时间 Mock
- [DOM 测试](https://bun.com/docs/test/dom) — 浏览器 DOM 测试
- [代码覆盖率](https://bun.com/docs/test/code-coverage) — 覆盖率报告
- [配置](https://bun.com/docs/test/configuration) — 测试配置
- [发现](https://bun.com/docs/test/discovery) — 测试文件发现
- [报告器](https://bun.com/docs/test/reporters) — 测试结果报告器
- [运行时行为](https://bun.com/docs/test/runtime-behavior) — 运行时行为说明
