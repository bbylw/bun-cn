# 打包器

Bun 内置了强大的打包器，支持多种打包场景。

## 核心功能

- [`Bun.build`](https://bun.com/docs/bundler/index) — 打包 API 入口
- [加载器](https://bun.com/docs/bundler/loaders) — 文件加载器
- [插件](https://bun.com/docs/bundler/plugins) — 打包器插件系统
- [宏](https://bun.com/docs/bundler/macros) — 编译时宏
- [对比 esbuild](https://bun.com/docs/bundler/esbuild) — 与 esbuild 的对比
- [单文件可执行程序](https://bun.com/docs/bundler/executables) — 编译为可执行文件
- [CSS](https://bun.com/docs/bundler/css) — CSS 打包支持
- [HTML 与静态站点](https://bun.com/docs/bundler/html-static) — HTML 打包
- [模块热替换（HMR）](https://bun.com/docs/bundler/hot-reloading) — 开发时热重载
- [使用 HTML 导入的全栈开发](https://bun.com/docs/bundler/fullstack) — 全栈 HTML 导入
- [独立 HTML](https://bun.com/docs/bundler/standalone-html) — 独立 HTML 文件
- [字节码缓存](https://bun.com/docs/bundler/bytecode) — 字节码缓存优化
- [压缩器](https://bun.com/docs/bundler/minifier) — 代码压缩
